Gerenciador de Tarefas Web

Aplicação web desenvolvida para organizar e gerenciar tarefas diárias de forma prática e intuitiva diretamente no navegador.

Funcionalidades

- Adicionar novas tarefas
- Marcar tarefas como concluídas
- Editar e excluir tarefas existentes
- Filtrar tarefas por status (todas, pendentes, concluídas)
- Persistência de dados no navegador (`localStorage`)
- Gráfico de atividades

Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
